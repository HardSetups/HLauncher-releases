# HLauncher — sürümler

Bu repo yalnızca **HLauncher**'ın derlenmiş kurulum dosyalarını, otomatik
güncelleme beslemesini (`latest.yml`) ve launcher haber akışını
(`news.json`) barındırır. Kaynak kod burada değildir.

- **İndir:** [Releases](https://github.com/HardSetups/HLauncher-releases/releases) →
  en yeni sürümdeki `HLauncher-Kurulum-<sürüm>.exe`
- Her sürümde `SHA256SUMS.txt` bulunur; indirdiğin dosyayı doğrulamak için:
  `Get-FileHash .\HLauncher-Kurulum-<sürüm>.exe -Algorithm SHA256`
- Kurulu launcher kendini bu repodan otomatik günceller.

HLauncher, Mojang veya Microsoft ile bağlantılı değildir.
